# S.U.Z. Reinigung - Contract Generator

Professional employment contract generator for S.U.Z. Reinigung. Create legally compliant employment contracts online with our user-friendly interface.

## 🌟 Features

- **Multiple Contract Types**: Support for Minijob, Teilzeit (Part-time), and Vollzeit (Full-time) contracts
- **PDF Generation**: Generate professional PDF contracts instantly
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **German Language**: Fully localized for German employment law
- **Professional Templates**: Legally compliant contract templates
- **User-Friendly Interface**: Intuitive form-based contract creation

## 🚀 Live Demo

Visit the live application: [https://suzreinigung.github.io/suz-contract-generator](https://suzreinigung.github.io/suz-contract-generator)

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Styling**: Custom CSS with modern design principles
- **PDF Generation**: Client-side PDF generation
- **Icons**: Custom favicon set for all devices
- **PWA**: Progressive Web App capabilities

## 📱 Browser Support

- Chrome (recommended)
- Firefox
- Safari
- Edge
- Mobile browsers (iOS Safari, Chrome Mobile)

S.U.Z. Reinigung is a professional cleaning service company providing high-quality cleaning solutions. This contract generator streamlines the employment process by providing legally compliant contract templates.
